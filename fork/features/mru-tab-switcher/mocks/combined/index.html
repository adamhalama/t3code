Recent thread switcher: combined Quick Open list + sidebar-native

Round 2 for fork/features/mru-tab-switcher/SPEC.md. Back to round 1: the five original directions.

The idea. The sidebar is always the primary switcher: while Ctrl is held, the thread you will jump to is highlighted in the sidebar, other rows dim, MRU badges 1–9 replace the time slot, and a collapsed shelf (Settled) opens just enough to show the selected thread. If the sidebar is collapsed, a slim panel slides in instead. At the same time a Quick Open-style list mirrors the same selection. The list can be folded into a small pill that only says “you are in a Ctrl+Tab switch”; with the list folded the sidebar highlight alone carries the selection. The folded/expanded choice is remembered for the next Ctrl+Tab (here: localStorage key mru-combined-list); there is no Settings entry.

How to use the mocks

  • Hold Ctrl or Alt and press ` (Shift+` for previous). Release to open the selection, Esc cancels, a quick tap goes to the previous thread with no UI. Real Ctrl+Tab works where the browser passes it through (Electron).
  • While the switcher is open, Ctrl+L (or Alt+L in the simulation) folds or unfolds the list. Clicking the chevron, button, chip or pill with Ctrl still held toggles too, and does not commit or close the switcher; only releasing Ctrl commits.
  • Fold the list, release, then hold Ctrl again: the switcher reopens folded. The DEMO strip shows the saved value and has “Toggle list” and “Forget saved list choice”.
  • URL states: open (list, 2nd selected), cycled (4th selected, a thread in the collapsed Settled shelf), pill, cycled-pill, sidebar-collapsed, sidebar-collapsed-pill, single, long. Add &demo=0 to hide the demo strip. Presets that show the switcher also set the saved list choice.
  • The numbered selector (top right) switches variations and keeps ?state=; number keys 1–5 do the same.

Why the toggle key is Ctrl+L

  • It only exists while the switcher is open, so it shadows no app binding. “L” for list.
  • Rejected: Ctrl+Space switches input source on macOS and toggles the IME on some Windows (CJK) and Linux (fcitx) setups; Ctrl+↑/↓ open Mission Control on macOS and arrows already move the selection.
  • Risk: in a plain browser tab Ctrl+L focuses the address bar unless the page prevents it (it can).
