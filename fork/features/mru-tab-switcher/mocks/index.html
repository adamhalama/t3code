Static mocks for fork/features/mru-tab-switcher/SPEC.md. Each page is a replica of the T3 Code desktop window (dark theme) with one switcher design. Pick one direction; nothing is implemented yet.

Round 2: the owner picked a combination of 1 (Quick Open list) and 3 (Sidebar-native). Five variations of that combination are in combined/.

How to use the mocks

  • Browser-safe keys: hold Ctrl or Alt and press ` (Shift+` for previous). Release the modifier to open the selection, Esc cancels. A quick tap switches to the previous thread without showing anything (150 ms hold delay).
  • Real Ctrl+Tab / Ctrl+Shift+Tab also work where the browser lets the page see them (for example inside Electron).
  • The yellow DEMO strip at the bottom left is tooling, not part of the design: Tap, Hold+Next, Next, Previous, Release, Esc, and static presets for screenshots.
  • URL states: ?state=open (2nd selected), cycled (4th selected), single (only one thread, Ctrl+Tab does nothing), long (long titles, picker open), collapsed (sidebar collapsed, picker open). Add &demo=0 to hide the demo strip.
  • The numbered selector (top right) switches variants and keeps the ?state=; number keys 1-5 do the same.
  • Committing a thread updates the open thread and the recent order, so you can keep switching.

Fixtures: 3 projects, 9 threads, sidebar order (activity) deliberately differs from the recent order. One thread runs on a remote environment (devbox), one has a very long title, and statuses cover working, approval, input, failed, done and idle.
